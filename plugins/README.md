# Plugins

Bundled plugins, one folder per plugin (`plugins/<id>/` with `plugin.json`, `checks/`,
`actions/`, `consume/`, `i18n/` and `tests/`). The reference plugin `java` follows in
work package AP-13; the remaining bundled plugins, including the language packs
`lang-de` and `lang-en`, follow in AP-17 to AP-19 and AP-28.
