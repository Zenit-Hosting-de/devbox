# web

The DevBox web interface: Angular 22 (standalone components, signals, `OnPush`, zoneless) with
[zenit-ui](https://www.npmjs.com/package/@zenit-hosting/zenit-ui) as the only component library.
The UI contains no code for single plugins; every page is built from manifests, check results
and schemas.

## Run

| Command | What it does |
| --- | --- |
| `make dev-mock` | UI on `http://localhost:4200` against typed mock data. No core needed. |
| `make dev` | Core (`devbox serve --allow-origin http://localhost:4200`) and `ng serve` with a proxy for `/api`. |
| `make build` | Production build into `internal/api/dist/ui/`, then the Go binary that embeds it. |
| `npm --workspace web test` | Vitest through the Angular unit-test builder (jsdom, no browser). |

`ng serve --configuration mock` replaces the transport: `src/app/mock/` answers `/api/v1/*` from
fixtures that are checked against the OpenAPI types, and a `MockSocket` simulates sessions
(coloured output, step, progress and result events, a `sudo` prompt, cancel, resume with
`fromSeq`). The same mocks run in the unit tests.

## Layout

| Path | Content |
| --- | --- |
| `src/app/api/` | Typed `ApiClient`, the interceptor (CSRF header, problem parsing), contract types |
| `src/app/stores/` | One signal store per area; `SessionsStore` owns the only WebSocket |
| `src/app/ws/` | Socket abstraction, session channels (sequence handling), event summaries |
| `src/app/schema-form/` | `SchemaForm`: forms from plugin field schemas, `optionsFrom`, validation |
| `src/app/settings/` | Settings group (shared by the settings page and the plugin page), appearance |
| `src/app/actions/` | Action dialog (parameters, dry run, confirmation) and launcher |
| `src/app/terminal/`, `src/app/shell/` | xterm.js terminal (loaded lazily), terminal dock, application shell |
| `src/app/pages/` | Overview, plugins, plugin detail, history, settings, credentials |
| `src/app/mock/` | Mock backend, interceptor and socket |
| `src/i18n/` | Core texts (`de.json`, `en.json`); plugin texts come from `GET /plugins/{id}/messages/{lang}` |
| `src/app/gen/` | Generated by `make generate`; never edited by hand |

## Rules

- Styles use zenit-ui tokens (`var(--…)`) only; no hex or pixel values, no Angular Material.
- Texts are neutral and exist in German and English. A missing key shows English, then the key.
- No URL literals other than `localhost` and `example.com`.
- The production build sends no inline scripts (the core's CSP is `script-src 'self'`); the theme
  init script is the file `public/theme-init.js`, generated with `zenitThemeInitScript` for the
  storage key `devbox.theme`.
